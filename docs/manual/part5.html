Part 5

Customising

Make Studio look the way you like, and keep your settings: how Studio saves them for you, and how to save, share and reset a stage's settings yourself.

20 Settings and themes #

The theme popout

The theme button at the top of the window, beside the stage tabs, shows the theme you're using. Click it for everything about the look:

  • Themes, in two groups. Dark themes: Graphite, True Black, The Nile, Ink, Nord, Warm Carbon, Plum, Teal Slate and Moss. Light themes: Light, Paper, Frost, Orchid, Sea Glass, Bone and Fern. Click one and the window changes straight away.
  • Frosted Glass: your desktop shows through behind the window, blurred. The Opacity knob sets how much of the theme's colour stays over the glass (30 to 90%); lower is more see-through. Double-click it for Auto, the theme's own setting.
  • UI Scale makes everything bigger or smaller, from 75% to 100%. Double-click the knob for Auto, which picks a size to suit your screen.
  • Section Outlines: a thin outline around each panel.
  • Film Grain: a fine film grain over the window and its popups, tuned for each theme. The video previews are always kept clean, so it's never mistaken for grain in the picture.
  • App Icon: Studio's icon in fifteen colours, Matte or Glossy, or the Classic one. It changes live on the window, the title bar, the taskbar, the notifications and Studio's shortcuts on the desktop and the taskbar (see making a desktop shortcut).
TipOn a light theme, keep the glass Opacity at 60% or more: below that, the desktop behind can make the text harder to read.
Want other colours?You can add as many themes of your own as you like. Studio's extra themes are listed in studio/shell.py, under _EXTRA_THEMES; the notes above it say what each colour is for. Send that file to an AI chat assistant (an LLM) and tell it the colours you'd like, for example "add a dark theme called Forest, deep green with a white accent". Put the file it gives you back in place and restart Studio: the new theme is in the list. Keep a copy of your version, as updating Studio can replace the file.

The Settings window

The gear (Ctrl+,) opens Settings. The list on the left has:

  • First, the options of the stage you're looking at, so the list changes as you change tabs. Each stage has a File group (see the next section), and most have a Help group with Debug Logging, which writes much more detail to the console, useful when asking for help.
  • Studio: Save All Settings, Set Project Folder, Check for Updates, Open Console and Exit.
  • Appearance: Show Tips (the tips above each stage's progress bar), Fit Window to Content (Ctrl+0), and the Projects Folder and TV Shows Folder (Part 1).
  • Keyboard Shortcuts: every shortcut, by where it works.
  • GPU: Release GPU Memory unloads the models the stages are keeping on the graphics card, to free it for something else. It can't be used while a job is running.

The window

Studio remembers the window's size and place, and grows the window when a page needs more room to show everything. If you've resized it by hand and want it back to the page's own size, press Ctrl+0.

21 Saving and loading settings #

Saved for you

You don't have to save anything. Every stage keeps its settings as you change them, and Studio saves them all when you close it, along with the theme, the window, and where each stage was in each project. Next time, everything is as you left it.

Settings → Studio → Save All Settings writes them all to disk straight away, if you'd rather not wait.

Three kinds of settings

A stage's settingsWhat you see on the page. They apply to every clip, unless the clip has its own.
A clip's sidecarOne clip's own settings, saved beside it in a .fssidecar file (Part 2, 8f). They win over the stage's settings for that clip, and they travel with it.
A settings fileA copy of a stage's settings you save yourself, to keep or to share (below).

Settings files

Each stage's File group in Settings (Inpainting V2 has the buttons on its page) can:

  • Save Settings to a file: a snapshot of the stage's settings. Keep one for a look you like, or give it to someone else so they get the same result.
  • Load Settings from a file: put a saved snapshot back.
  • Reset to Default: every setting of that stage back to how Studio came. It asks first.
TipBefore trying something very different on a stage, save its settings to a file first. If you don't like the result, load the file and you're back where you were.

Sidecar options (Splatting)

Splatting's File group also decides how sidecars are used:

  • Update Slider from Sidecar: when you move to a clip that has a sidecar, the page's knobs show its values.
  • Auto Save Sidecar on Next: changes to a clip that already has a sidecar are saved into it as you move to another clip, and keyframe edits straight away. A clip without a sidecar still needs Create Sidecar the first time.
  • Sidecars to Source and Sidecars to Depth move all the sidecars from the Depth Maps folder to the Source Clips folder, or back. Both ask first.
